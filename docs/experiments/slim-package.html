Removed non-English UI translations and dictionary bundles, offline help, galleries, templates/wizards, optional extensions, surplus icon themes and non-English Electron locales. Kept the English dictionary/hyphenation bundle, core document configuration, all document filters and the Colibre theme family. Retained upstream engine files are byte-identical.

Native code, editing behavior and temporary profile/startup handling were not changed. Unicode text support remains; multilingual UI and dictionary/hyphenation resources were reduced. Check the layout of multilingual documents locally.

Test this build locally
  1. Run Nebula-Doc-Slim-Experiment-Setup-0.1.2-slim.1.exe from release/slim-experiment. The installed shortcut is Nebula Doc Slim Experiment.
  2. Use a copy of the agreement. Open it, edit text and fonts, change the Signature Code line, create/rename/delete a bookmark, save a copy and reopen it.
  3. Compare installation time, launch time and first/repeated document opens with the standard app. Review tables, signature layout, headers and footers in Word if available.

The installer is unsigned. A portable unpacked application is also available in release/slim-experiment/win-unpacked. No installer was installed on this development machine.
