Dashed marker: 3 seconds. Time spent choosing a file is excluded. First opens made immediately after launch include engine initialization and have no three-second gate, as agreed.

The main change is removing small cross-process calls.

An application-owned Python component now reads and edits the document inside LibreOffice. Only a JSON request and response cross the process boundary for each operation. The engine starts in the background, reuses its private profile, and warms the binary Word filter with a generated scratch document. The renderer also avoids repeating document serialization on unrelated UI changes.

The benchmark reloaded the same supplied 205 KB, seven-page document through the real packaged Electron UI. Every open produced 255 body paragraphs and 33 editable body bookmarks. It measures full document readiness, not an empty preview or cached document response. The native file picker was stubbed to remove human selection time.

Install and test on TrigBotic
  1. Close the current Nebula Doc Slim Experiment.
  2. Run Nebula-Doc-Slim-Experiment-Setup-0.1.2-slim.2.exe from Downloads after transfer. It updates the earlier experiment, while the original standard Nebula Doc installation remains separate.
  3. Allow the initial engine startup. Open a copy of the agreement, edit the signature line, fonts and bookmarks, save/reopen, and time later document openings.

These are development-machine measurements. TrigBotic's actual timings still need local confirmation; large or different documents can take longer. This is an unsigned test installer.

For the engine-ready cases, the harness waits for the actual ready status before opening a document. Readiness is reported after initialization and scratch-document warm-up finish. Warm-up duration remains part of startup and is not represented as a faster cold launch.

Windows filesystem/font caches were not flushed between runs. The first run uses a new application-data directory; later launches reuse it. Native code and the reduced resource selection are unchanged from the packaging experiment.
